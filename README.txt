# MindGuard

Tool : Python, Jupyter Notebook

Dataset : Student Depression Dataset (Kaggle)

## Project Description
MindGuard is a machine learning project that predicts whether a student may experience depression based on academic and lifestyle-related factors using Gaussian Naive Bayes Classification.

## Features Used
* Age
* Academic Pressure
* Study Satisfaction
* Work/Study Hours
* Financial Stress

## Target Variable
* Depression

## Key Results
Accuracy Score : 78.79%
Confusion Matrix:
[[8289 3276]
[2641 13695]]

## Prediction Example
Input Values:
* Age = 21
* Academic Pressure = 5
* Study Satisfaction = 2
* Work/Study Hours = 10
* Financial Stress = 5

Predicted Result:
* Student may be Depressed

## Technologies Used
* Python
* Pandas
* NumPy
* Scikit-Learn
* Gaussian Naive Bayes

## Outcome
Successfully developed a classification model to identify potential depression risk among students and evaluated performance using Accuracy Score and Confusion Matrix.
